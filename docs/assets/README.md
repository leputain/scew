# Brand assets

This directory contains the public visual identity used by the repository.

| File | Purpose | Provenance |
|---|---|---|
| `screw-avatar.png` | Original square project avatar | Supplied by the repository owner |
| `screw-cover-v1.png` | Wide README and social-preview cover | Generated from the supplied avatar for this project |

The cover intentionally contains no real chat screenshots, employee data,
Telegram IDs, hostnames, or production configuration.

Unless a separate asset license is added, the artwork is **not** automatically
covered by a future software license for the source code. Obtain permission from
the repository owner before redistributing or modifying these images outside the
project.
